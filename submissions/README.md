## Before you submit

1. Paste the real GitHub URL into the Update and Final Report where marked.
2. In the **final report**, replace every `>>> REQUIRED PERSONAL REFLECTION` / time-management placeholder with your own writing (course forbids AI-authored reflections).
3. Insert demo screenshots (or a short video) into the final report.
4. Optionally re-run generator after edits to code/docs:

```bash
.\.venv\Scripts\python.exe scripts/generate_submissions.py
```

5. Upload each `.docx` to the matching Navigate assignment dropbox.
